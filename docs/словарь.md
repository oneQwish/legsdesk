# Словарь терминов

Для удобства — с аналогиями из 1С.

| Термин | Что это | Аналогия в 1С |
|---|---|---|
| **Дело** | Судебное дело целиком: иск → решение → апелляция → кассация → исполнение. Одна запись на дело, сколько бы номеров у него ни было. | Элемент справочника «Судебные дела» |
| **УИД** | Уникальный идентификатор дела в ГАС «Правосудие» (вида `50RS0010-01-2025-000287-27`). Главный ключ дела: не меняется при смене номера, года, инстанции. | Уникальный идентификатор ссылки |
| **Номер дела / псевдоним** | `2-1459/2025`, `М-257/2025`, `33-…`, `88-…`. У дела может быть много номеров; все они ищутся. | Дополнительные реквизиты / история кодов |
| **Код суда** | Код суда из справочника судов (сейчас — справочника 1С). Номер дела уникален только вместе с судом. | Код элемента справочника «Суды» |
| **Поле дела** | Сверяемое значение: судья, дата решения, основной долг, неустойка… Список — в `backend/fields.toml`. | Реквизит |
| **Источник** | Откуда пришло значение: «1С», «отчёт», «OCR», «письмо» (цифровой оригинал Почты России), «реестр Excel»… Имя источника задаётся в настройках коннектора, список не фиксирован. | — |
| **Наблюдение** | Значение поля по одному источнику (+ ключ записи в источнике, ссылка на документ, страница, цитата). У одного поля может быть несколько наблюдений. | Запись регистра сведений «Значения по источникам» |
| **Статус поля** | Считается автоматически по наблюдениям: *подтверждено* (≥2 источника согласны), *один источник*, *конфликт* (источники расходятся), *возможна апелляция* (суммы при признаках обжалования), *решено юристом*. | — |
| **Конфликт** | Поле, где источники называют разные значения. Юрист выбирает верное или вводит своё с комментарием. | — |
| **Решение юриста** | Выбранное юристом значение поля. Пишется в журнал и уходит в ленту изменений. Если позже источник пришлёт *новое* значение — конфликт откроется снова. | Документ «Корректировка» |
| **Документ** | Файл (скан, PDF письма, акт, документ ФССП) и его карточка: вид акта, даты, трек, привязка к делу. Одинаковые файлы (по sha256) не задваиваются. | Присоединённый файл + реквизиты |
| **Процессуальный срок** | Считается по ГПК из актов дела (апелляция, вступление в силу, кассация, частная жалоба, отмена заочного) с учётом производственного календаря. Можно добавить свой срок вручную. | — |
| **Производственный календарь** | Рабочие/нерабочие дни года с переносами. Загружается коннектором (из 1С или файла). | Регламентированный производственный календарь (БСП) |
| **Журнал** | Все действия людей и сервисов: кто, что, когда, было/стало. | Журнал регистрации |
| **Лента изменений** | Тот же журнал, выдаваемый внешним системам по порядку с курсором: «дай всё новое после N». Ничего не теряется и не дублируется. | Планы обмена (регистрация изменений) |
| **Курсор** | Номер последнего прочитанного события ленты. Коннектор хранит его в файле, 1С — в константе/регистре. | Номер принятого сообщения обмена |
| **Сервис** | Внешняя программа, подключённая к рабочему месту (коннектор, конвейер распознавания, 1С). Имеет свои API-ключи и права. | Пользователь ИБ для обмена |
| **API-ключ** | Пароль сервиса вида `ldk_xxxxxxxx_…`. Показывается один раз при выдаче, отзывается мгновенно. | Пароль пользователя обмена |
| **Область доступа (scope)** | Что разрешено сервису: `read` — читать, `ingest` — загружать, `tasks` — очередь задач, `export` — лента и выгрузка, `calendar` — календарь. | Роль |
| **Коннектор** | Настройка обмена с одной системой в файле `.toml` + универсальная программа `lawdesk_connect.py`, которая её выполняет. | Правило обмена (КД) |
| **Подборка** | Сохранённый набор фильтров. Можно выложить стопкой на «Стол». | Сохранённая настройка отбора |
| **Задача (очередь)** | Поручение сервису («распознать файл», «скачать письмо»), которое он забирает и выполняет. | Регламентное/фоновое задание |
