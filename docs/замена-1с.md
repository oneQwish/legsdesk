# Путь к замене 1С

Документ для руководителя и команды: что в рабочем месте уже готово к тому, чтобы когда-нибудь заменить
1С (Юрайт) в судебной работе, чего не хватает и как переходить без остановки работы.

## 1. Что уже сделано так, чтобы не зависеть от 1С

| Решение | Почему это важно для замены |
|---|---|
| Дело идентифицируется **УИДом** (из ГАС «Правосудие»), а не ссылкой 1С | ключ дела не пропадёт вместе с 1С |
| Источник значения — **просто имя** («1С», «отчёт», «OCR», …) | 1С можно заменить другим источником, переименовать или убрать без переделки |
| Обмен — **коннекторами по настройкам** (CSV, Excel, JSON, OData, HTTP, SQL) | новая система подключается так же, как 1С; одинэсники сопровождают обмен без программиста |
| Наружу — **лента изменений** с курсором + коннектор `out` | любая система (1С сейчас, другая потом) получает решения одинаково |
| Справочник полей — **файл `fields.toml`** | новые поля добавляются без программиста |
| Файлы документов — через **адаптер хранилища** | можно хранить на сервере, в 1С:Документообороте или другой системе |
| Журнал всех действий | история не теряется при смене системы-владельца |

## 2. Кто сейчас «владелец» каких данных

| Данные | Сейчас владелец | Рабочее место |
|---|---|---|
| Реестр дел, стороны, суды, договоры | 1С | получает копию, сверяет с OCR/письмами/отчётами |
| Итоговые значения спорных полей | рабочее место (решение юриста) | отдаёт в 1С |
| Процессуальные сроки | рабочее место | считает по актам |
| Документы (сканы, письма) и их связь с делами | рабочее место | хранит, привязывает |
| Справочник судов, юрлиц | 1С | получает код суда и юрлицо в деле |
| Финансы (оплата госпошлин, расходы, исполнение) | 1С | не ведёт |

## 3. Этапы перехода

Переход постепенный: на каждом этапе обе системы работают, и в любой момент можно остановиться.

**Этап 0 — сейчас.** 1С — источник реестра; рабочее место — сверка, решения, сроки, документы.

**Этап 1 — рабочее место ведёт судебные реквизиты.** Юристы правят судью, даты, суммы, исход прямо в
рабочем месте; 1С получает их коннектором `out`. В 1С эти реквизиты становятся «только для чтения».
*Что нужно доделать:* редактирование любого поля дела из карточки (сейчас — через разрешение конфликта
или «своё значение»), права на правку по ролям/юрлицам.

**Этап 2 — новые дела заводятся в рабочем месте.** Карточка нового дела (из иска), загрузка иска,
назначение ответственного. 1С получает новые дела коннектором `out`.
*Нужно:* форма создания дела; справочники судов и юрлиц внутри рабочего места (сейчас — код и
наименование в деле); дедупликация при заведении (поиск по УИД/номеру уже есть).

**Этап 3 — справочники и связанные учёты.** Суды, юрлица, договоры/объекты, контрагенты-истцы;
исполнительные производства (документы ФССП уже принимаются); задачи и поручения юристам; отчёты
комитету.
*Нужно:* соответствующие разделы; отчёты (сейчас — выгрузки и фильтры/подборки).

**Этап 4 — 1С только получает.** Все изменения идут из рабочего места; 1С (если ещё нужна для финансов)
получает данные коннектором. Источник «1С» в рабочем месте выключается.

**Этап 5 — отключение 1С в судебной части.** Архив 1С выгружается в рабочее место (коннектор csv/odata
по всей истории) — как источник «1С (архив)», чтобы старые значения остались видны рядом с текущими.

## 4. Чего не хватает до полной замены (честно)

| Возможность Юрайта / 1С | В рабочем месте |
|---|---|
| Ведение реестра дел, карточка дела | есть (просмотр, сверка, сроки, документы); **нет** создания и свободной правки |
| Справочники судов, юрлиц, контрагентов | **нет** (только код/название в деле) |
| Задачи, поручения, контроль исполнения | частично: процессуальные сроки, свои сроки; **нет** поручений |
| Исполнительные производства | приём документов ФССП; **нет** учёта ИП и взысканий |
| Финансы: госпошлины, расходы, оплаты | **нет** (и, возможно, не нужно — остаётся в учётной системе) |
| Печатные формы (иски, возражения, письма) | **нет** |
| Отчётность | фильтры, подборки, выгрузки XLSX/CSV; **нет** конструктора отчётов |
| Права по юрлицам/подразделениям | роли по группам AD; **нет** ограничения по юрлицам |
| Интеграции (парсер судов, Почта, ФССП) | приём через коннекторы и API — готов |

## 5. Правила, которые помогут перейти безболезненно

1. **Ключ дела — УИД.** Добивайтесь УИД у всех дел (фильтр «УИД: нет» показывает, где его не хватает).
2. **Не связывайте обмен с внутренними ссылками 1С.** В коннекторах используйте УИД, код суда, номер; ссылку
   1С (`Ref_Key`) — только как `source_ref` (ключ записи источника).
3. **Новые поля — в `fields.toml`**, а не «где-то в 1С».
4. **Источники называйте по смыслу**, а не по программе: «реестр дел», «отчёт юристов», «цифровое письмо».
   Тогда при замене программы имя источника не придётся менять.
5. **При переходе источника на новую систему** сначала подключите её как *новый* источник рядом со старым —
   расхождения сразу видны как конфликты. Когда расхождений не останется, отключите старый.
6. **Не правьте данные в обход API** (прямо в базе): так теряется журнал и лента изменений.
