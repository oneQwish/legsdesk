# План развития

Согласован с заказчиком 22.10.2026. Каждый этап даёт законченный результат; порядок можно менять.

## Решения, принятые при согласовании

| Вопрос | Решение |
|---|---|
| Пилот | Проводит заказчик сам, на тестовых данных, пока нет доступа к 1С. Нужен «набор для пилота» |
| Объём | Этапы 1–4 берём; этап 5 (ИИ) — не сейчас |
| Уведомления | Пока только внутри системы; сделать **сервис уведомлений с каналами**, чтобы позже подключить почту/мессенджер без переделки |
| Права по юрлицам | Не нужны — всё как есть (роли admin / lawyer / viewer) |
| Журнал просмотров ПДн (152-ФЗ) | Пока не нужен |
| Календарь заседаний | Уже есть отдельный сервис (rasp.gslegalteam.ru) — **не делаем свой**, а подключаем его как источник |

## Этап 0. Набор для пилота (делает заказчик сам)

- Генератор правдоподобных тестовых данных: сотни дел по трём юрлицам, расхождения источников, акты, сроки,
  календарь — вместо 60 демо-дел.
- Пошаговый сценарий пилота: что проверить, где смотреть, куда записывать замечания.
- Запуск одной командой на своём компьютере (без сервера компании).

## Этап 1. Юрист ведёт дело в системе

- Правка любого поля дела из карточки (журнал + лента изменений → внешние системы).
- Создание дела вручную с проверкой дублей по УИД и номеру.
- Справочники судов и юрлиц внутри системы.

## Этап 2. Ежедневная работа

- Поручения юристам: кто, что, к какому сроку, отметка выполнения; на «Столе».
- Сервис уведомлений: события (срок через N дней, срок сегодня, новое поручение, новый конфликт по моему
  делу) → каналы. Сейчас канал один — «в системе» (колокольчик, сводка на «Столе»); почта и мессенджер
  добавляются позже настройкой.
- Заседания из сервиса расписания (rasp.gslegalteam.ru) — коннектором; показ в ленте дней, карточке и
  хронологии дела.

## Этап 3. Документы

- Печатные формы: шаблоны Word с подстановкой данных дела.
- Полнотекстовый поиск по текстам решений (OCR) с подсветкой.
- Подключение 1С:Документооборота вместо локального хранилища — когда будет доступ.

## Этап 4. Исполнение и отчёты

- Исполнительные производства: документы ФССП, суммы, статусы, сроки предъявления.
- Аналитика: присуждено/заявлено по ЖК, корпусам, судьям, периодам; обжалования; нагрузка юристов.
- Отчёты для руководства (XLSX/PDF), в том числе по расписанию.

## Сквозное

- Автотесты в GitHub при каждом изменении (CI).
- Ускорение «Стола» (один сводный запрос) и проверка на большом объёме дел.
- Проверка на реальной 1С, AD и sot.db — когда появится доступ (остаётся открытым из этапа 0).

## Отложено

- Этап 5 (ИИ): извлечение реквизитов, подсказки при конфликтах, черновики жалоб.
- Права по юрлицам, журнал просмотров персональных данных.
