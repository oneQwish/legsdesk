# Обмен с 1С: руководство для разработчика 1С

Есть два способа связать 1С с рабочим местом. Их можно сочетать.

| Способ | Кто что делает | Когда выбирать |
|---|---|---|
| **А. Коннектор** (без кода на стороне рабочего места) | 1С публикует данные (OData или HTTP-сервис) и/или принимает решения (HTTP-сервис); коннектор `lawdesk_connect.py` по расписанию забирает и отдаёт | Почти всегда: проще сопровождать, логика обмена видна в файле настроек |
| **Б. Код 1С вызывает API** | 1С сама отправляет данные и забирает изменения регламентным заданием | Когда нужна немедленная реакция (записали документ — сразу отправили) или сложная логика на стороне 1С |

Содержание:
1. [Опубликовать OData](#1-опубликовать-odata) — для способа А, чтение данных из 1С
2. [HTTP-сервис 1С, отдающий данные](#2-http-сервис-1с-отдающий-данные) — способ А, если OData не подходит
3. [Общий модуль для вызова API](#3-общий-модуль-лд_обмен) — способ Б
4. [Отправка дел и значений из 1С](#4-отправка-дел-и-значений-из-1с) — способ Б
5. [HTTP-сервис 1С, принимающий решения](#5-http-сервис-1с-принимающий-решения) — способ А, приём
6. [Чтение ленты изменений из 1С](#6-чтение-ленты-изменений-регламентным-заданием) — способ Б, приём
7. [Производственный календарь](#7-производственный-календарь)
8. [Справка по API](#8-справка-по-api)

Все примеры — для платформы 8.3.10 и новее. Имена объектов (`Справочник.СудебныеДела` и т. п.)
замените на свои.

---

## 1. Опубликовать OData

1. **Конфигуратор → Администрирование → Публикация на веб-сервере.** Отметьте «Публиковать стандартный
   интерфейс OData». Нужен веб-сервер (IIS или Apache) на сервере 1С.
2. **Разрешить объекты.** По умолчанию в OData ничего не видно. Выполните один раз в режиме
   1С:Предприятие (внешняя обработка или консоль кода):
   ```bsl
   Состав = Новый Массив;
   Состав.Добавить(Метаданные.Справочники.СудебныеДела);
   Состав.Добавить(Метаданные.Справочники.Суды);
   Состав.Добавить(Метаданные.РегистрыСведений.ДанныеПроизводственногоКалендаря);
   УстановитьСоставСтандартногоИнтерфейсаOData(Состав);
   ```
   (Или стандартной обработкой «Настройка автоматического REST-сервиса», если она есть в конфигурации.)
3. **Пользователь только для чтения**, например `lawdesk_reader`, с ролью, дающей чтение этих объектов.
   Пароль сохраните в `connectors/секреты.bat` (переменная `LAWDESK_1C_PASSWORD`).
4. **Проверка в браузере:** `http://сервер/база/odata/standard.odata/` — список объектов;
   `http://сервер/база/odata/standard.odata/Catalog_СудебныеДела?$format=json&$top=3` — три записи.
5. Возьмите заготовку `connectors/примеры/1с_odata.toml` и впишите адрес, объект и реквизиты.

Подсказки по OData 1С:
- имена: `Catalog_Имя`, `Document_Имя`, `InformationRegister_Имя`, `AccumulationRegister_Имя`;
- ссылка на другой объект приходит как `Реквизит_Key` (GUID); чтобы взять его реквизиты, укажите
  `expand = "Реквизит"` и обращайтесь `{Реквизит.Description}`, `{Реквизит.Code}`;
- стандартные поля: `Ref_Key`, `Code`, `Description`, `DeletionMark`, для документов `Number`, `Date`, `Posted`;
- фильтр: `filter = "DeletionMark eq false and Date ge datetime'2027-01-01T00:00:00'"`.

## 2. HTTP-сервис 1С, отдающий данные

Если OData нельзя или нужен свой запрос (соединения, вычисления), сделайте HTTP-сервис.

**Конфигуратор:** Общие → HTTP-сервисы → добавить `ЛД_Обмен`, корневой URL `lawdesk`.
Шаблон URL `/cases`, метод `GET`, обработчик `casesGET`. Адрес будет
`http://сервер/база/hs/lawdesk/cases`.

```bsl
// Модуль HTTP-сервиса ЛД_Обмен
Функция casesGET(Запрос)

	Запрос1С = Новый Запрос;
	Запрос1С.Текст =
	"ВЫБРАТЬ
	|	Дела.Ссылка КАК Ссылка,
	|	Дела.УИД КАК УИД,
	|	Дела.НомерДела КАК НомерДела,
	|	Дела.Суд.Код КАК КодСуда,
	|	Дела.Суд.Наименование КАК Суд,
	|	Дела.Судья КАК Судья,
	|	Дела.ЗаявленнаяСумма КАК Заявлено
	|ИЗ
	|	Справочник.СудебныеДела КАК Дела
	|ГДЕ
	|	НЕ Дела.ПометкаУдаления";
	Выборка = Запрос1С.Выполнить().Выбрать();

	Записи = Новый Массив;
	Пока Выборка.Следующий() Цикл
		Запись = Новый Структура;
		Запись.Вставить("ref", Строка(Выборка.Ссылка.УникальныйИдентификатор()));
		Запись.Вставить("uid", Выборка.УИД);
		Запись.Вставить("number", СокрЛП(Выборка.НомерДела));
		Запись.Вставить("court_code", Выборка.КодСуда);
		Запись.Вставить("court", Выборка.Суд);
		Запись.Вставить("judge", Выборка.Судья);
		Запись.Вставить("claim", Формат(Выборка.Заявлено, "ЧРД=.; ЧГ=0; ЧН=")); // 1200000.50
		Записи.Добавить(Запись);
	КонецЦикла;

	Результат = Новый Структура("items, next", Записи, Null); // next = null: всё в одном ответе
	Возврат ОтветJSON(Результат);

КонецФункции

Функция ОтветJSON(Данные, КодСостояния = 200)
	ЗаписьJSON = Новый ЗаписьJSON;
	ЗаписьJSON.УстановитьСтроку();
	ЗаписатьJSON(ЗаписьJSON, Данные);
	Ответ = Новый HTTPСервисОтвет(КодСостояния);
	Ответ.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
	Ответ.УстановитьТелоИзСтроки(ЗаписьJSON.Закрыть(), КодировкаТекста.UTF8, ИспользованиеByteOrderMark.НеИспользовать);
	Возврат Ответ;
КонецФункции
```
Коннектор: заготовка `connectors/примеры/1с_http.toml` (`items_path = "items"`, `next_path = "next"`).

> Даты отдавайте строкой `Формат(Дата, "ДФ=yyyy-MM-dd")`, суммы — с точкой и без разделителей групп
> (`"ЧРД=.; ЧГ=0"`): так их однозначно поймёт любой приёмник.

## 3. Общий модуль `ЛД_Обмен`

Для способа Б. Создайте общий модуль `ЛД_Обмен` (Сервер, Вызов сервера — нет) и константы:
`ЛД_АдресСервера` (Строка, например `lawdesk.company.local`), `ЛД_КлючAPI` (Строка, доступ — только
администратору), `ЛД_КурсорЛенты` (Число, 15.0).

```bsl
// Выполнить запрос к API рабочего места. Данные — Структура/Массив (будут переданы как JSON).
// Возвращает прочитанный JSON (Структура/Массив) или Неопределено.
Функция Запрос(Метод, Адрес, Данные = Неопределено) Экспорт

	Защищенное = Новый ЗащищенноеСоединениеOpenSSL(Неопределено, Новый СертификатыУдостоверяющихЦентровОС);
	Соединение = Новый HTTPСоединение(Константы.ЛД_АдресСервера.Получить(), 443, , , , 60, Защищенное);

	HTTPЗапрос = Новый HTTPЗапрос(Адрес);
	HTTPЗапрос.Заголовки.Вставить("Authorization", "Bearer " + Константы.ЛД_КлючAPI.Получить());
	HTTPЗапрос.Заголовки.Вставить("Accept", "application/json");
	Если Данные <> Неопределено Тогда
		ЗаписьJSON = Новый ЗаписьJSON;
		ЗаписьJSON.УстановитьСтроку();
		ЗаписатьJSON(ЗаписьJSON, Данные);
		HTTPЗапрос.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
		HTTPЗапрос.УстановитьТелоИзСтроки(ЗаписьJSON.Закрыть(), КодировкаТекста.UTF8, ИспользованиеByteOrderMark.НеИспользовать);
	КонецЕсли;

	Ответ = Соединение.ВызватьHTTPМетод(Метод, HTTPЗапрос);
	Текст = Ответ.ПолучитьТелоКакСтроку(КодировкаТекста.UTF8);
	Если Ответ.КодСостояния >= 300 Тогда
		ВызватьИсключение СтрШаблон(НСтр("ru = 'Рабочее место юриста: %1 %2 → HTTP %3: %4'"),
			Метод, Адрес, Ответ.КодСостояния, Лев(Текст, 500));
	КонецЕсли;
	Если ПустаяСтрока(Текст) Тогда
		Возврат Неопределено;
	КонецЕсли;
	ЧтениеJSON = Новый ЧтениеJSON;
	ЧтениеJSON.УстановитьСтроку(Текст);
	Возврат ПрочитатьJSON(ЧтениеJSON);

КонецФункции

// Ссылка на дело для API: по УИД, иначе по коду суда и номеру.
Функция СсылкаНаДело(УИД, КодСуда = "", НомерДела = "") Экспорт
	Результат = Новый Структура;
	Если ЗначениеЗаполнено(УИД) Тогда
		Результат.Вставить("uid", СокрЛП(УИД));
	Иначе
		Результат.Вставить("court_code", СокрЛП(КодСуда));
		Результат.Вставить("case_number", СокрЛП(НомерДела));
	КонецЕсли;
	Возврат Результат;
КонецФункции

Функция ДатаISO(Дата) Экспорт
	Возврат ?(ЗначениеЗаполнено(Дата), Формат(Дата, "ДФ=yyyy-MM-dd"), "");
КонецФункции

Функция СуммаСтрокой(Сумма) Экспорт
	Возврат Формат(Сумма, "ЧРД=.; ЧГ=0; ЧН=0.00; ЧДЦ=2");
КонецФункции
```
Если сервер работает по `http` (тестовый стенд), уберите `Защищенное` и укажите порт `80` (или `8000`).

Ключ: в рабочем месте «Сервисы и API» → «Подключить сервис» → имя `1c-ura`, области `read`, `ingest`
(для отправки) и `export` (для чтения ленты), `calendar` (если 1С будет загружать календарь).

## 4. Отправка дел и значений из 1С

Пакетами до 1000 записей. Повторная отправка безопасна.

```bsl
// Отправить дело и значения его полей (например, из обработчика записи справочника или регламентного задания).
Процедура ОтправитьДело(Дело) Экспорт

	ДелоJSON = Новый Структура;
	ДелоJSON.Вставить("uid", Дело.УИД);
	ДелоJSON.Вставить("court_code", Дело.Суд.Код);
	ДелоJSON.Вставить("court_name", Дело.Суд.Наименование);
	ДелоJSON.Вставить("case_number", СокрЛП(Дело.НомерДела));
	ДелоJSON.Вставить("legal_entity", Дело.Ответчик.Наименование);
	Результат = ЛД_Обмен.Запрос("POST", "/api/v1/ingest/cases", ОдинЭлемент(ДелоJSON));
	ПроверитьРезультат(Результат);

	Ссылка = ЛД_Обмен.СсылкаНаДело(Дело.УИД, Дело.Суд.Код, Дело.НомерДела);
	КлючЗаписи = Строка(Дело.Ссылка.УникальныйИдентификатор());
	Значения = Новый Массив;
	ДобавитьЗначение(Значения, Ссылка, "judge", Дело.Судья, КлючЗаписи);
	ДобавитьЗначение(Значения, Ссылка, "claim_total", ЛД_Обмен.СуммаСтрокой(Дело.ЗаявленнаяСумма), КлючЗаписи);
	ДобавитьЗначение(Значения, Ссылка, "decision_date", ЛД_Обмен.ДатаISO(Дело.ДатаРешения), КлючЗаписи);
	Результат = ЛД_Обмен.Запрос("POST", "/api/v1/ingest/observations", Значения);
	ПроверитьРезультат(Результат);

КонецПроцедуры

Процедура ДобавитьЗначение(Значения, Ссылка, Поле, Значение, КлючЗаписи)
	Если Не ЗначениеЗаполнено(Значение) Тогда
		Возврат;   // пустые не отправляем
	КонецЕсли;
	Элемент = Новый Структура;
	Для Каждого КЗ Из Ссылка Цикл
		Элемент.Вставить(КЗ.Ключ, КЗ.Значение);
	КонецЦикла;
	Элемент.Вставить("field", Поле);
	Элемент.Вставить("source", "1С");          // имя источника, как его видят юристы
	Элемент.Вставить("source_ref", КлючЗаписи); // ключ записи: повтор обновит, а не задвоит
	Элемент.Вставить("value", Строка(Значение));
	Значения.Добавить(Элемент);
КонецПроцедуры

Функция ОдинЭлемент(Элемент)
	Массив = Новый Массив;
	Массив.Добавить(Элемент);
	Возврат Массив;
КонецФункции

// Пакетные методы отвечают списком: по каждому элементу ok / error / warnings.
Процедура ПроверитьРезультат(Результат)
	Для Каждого Элемент Из Результат Цикл
		Если Не Элемент.ok Тогда
			ЗаписьЖурналаРегистрации("ЛД.Обмен", УровеньЖурналаРегистрации.Ошибка, , , Строка(Элемент.error));
		ИначеЕсли Элемент.Свойство("warnings") И Элемент.warnings.Количество() > 0 Тогда
			ЗаписьЖурналаРегистрации("ЛД.Обмен", УровеньЖурналаРегистрации.Предупреждение, , ,
				СтрСоединить(Элемент.warnings, Символы.ПС));
		КонецЕсли;
	КонецЦикла;
КонецПроцедуры
```
Ключи полей (`judge`, `claim_total` …) — список в [коннекторы.md, раздел 7](коннекторы.md#7-поля-дела)
или запросом `GET /api/v1/fields`.

## 5. HTTP-сервис 1С, принимающий решения

Самый надёжный способ получать решения юристов: коннектор с `direction = "out"`
(заготовка `connectors/примеры/выгрузка_http.toml`) отправляет их POST-запросом в HTTP-сервис 1С.

Рекомендуемая схема: принятые записи складываются в **независимый регистр сведений** «ЛД_РешенияЮристов»
(измерение `ИдСобытия` — Строка(20); ресурсы: `УИД`, `КодСуда`, `НомерДела`, `Поле`, `Значение`,
`Комментарий`, `Автор`, `Момент` — строки; реквизит `Обработано` — Булево). Повторная запись с тем же
`ИдСобытия` просто перезапишет строку — дублей не будет. Применять решения к справочнику дел — отдельной
обработкой/регламентным заданием, по записям с `Обработано = Ложь`.

Шаблон URL `/decisions`, метод `POST`, обработчик `decisionsPOST`:
```bsl
Функция decisionsPOST(Запрос)

	Попытка
		ЧтениеJSON = Новый ЧтениеJSON;
		ЧтениеJSON.УстановитьСтроку(Запрос.ПолучитьТелоКакСтроку(КодировкаТекста.UTF8));
		Пакет = ПрочитатьJSON(ЧтениеJSON);
	Исключение
		Возврат ОтветJSON(Новый Структура("error", "некорректный JSON"), 400);
	КонецПопытки;

	НачатьТранзакцию();
	Попытка
		Для Каждого Элемент Из Пакет.items Цикл
			МЗ = РегистрыСведений.ЛД_РешенияЮристов.СоздатьМенеджерЗаписи();
			МЗ.ИдСобытия = Элемент.id;
			МЗ.Прочитать();                       // если уже было — обновим, не задвоим
			МЗ.ИдСобытия = Элемент.id;
			МЗ.УИД = Элемент.uid;
			МЗ.КодСуда = Элемент.court_code;
			МЗ.НомерДела = Элемент.case_number;
			МЗ.Поле = Элемент.field;
			МЗ.Значение = Элемент.value;
			МЗ.Комментарий = Элемент.note;
			МЗ.Автор = Элемент.author;
			МЗ.Момент = Элемент.at;
			МЗ.Записать();
		КонецЦикла;
		ЗафиксироватьТранзакцию();
	Исключение
		ОтменитьТранзакцию();
		ЗаписьЖурналаРегистрации("ЛД.Приём", УровеньЖурналаРегистрации.Ошибка, , , ОписаниеОшибки());
		Возврат ОтветJSON(Новый Структура("error", "ошибка записи — см. журнал регистрации"), 500);
	КонецПопытки;

	Возврат ОтветJSON(Новый Структура("accepted", Пакет.items.Количество()));

КонецФункции
```
Ответ не 200 → коннектор **не** сдвигает курсор и повторит пакет при следующем запуске.

Пользователь, под которым коннектор входит в 1С (`lawdesk_writer`), должен иметь право записи только
в этот регистр.

## 6. Чтение ленты изменений регламентным заданием

Альтернатива разделу 5: 1С сама забирает новые события.

```bsl
// Регламентное задание «ЛД: приём решений юристов», раз в 15 минут.
Процедура ПринятьРешенияЮристов() Экспорт

	Курсор = Константы.ЛД_КурсорЛенты.Получить();
	Пока Истина Цикл
		Адрес = СтрШаблон("/api/v1/changes?after=%1&actions=value_resolved&limit=500", Формат(Курсор, "ЧГ=0; ЧН=0"));
		Страница = ЛД_Обмен.Запрос("GET", Адрес);

		НачатьТранзакцию();
		Попытка
			Для Каждого Событие Из Страница.items Цикл
				ПрименитьРешение(Событие);
			КонецЦикла;
			// курсор сохраняем в той же транзакции, что и данные: либо всё, либо ничего
			Константы.ЛД_КурсорЛенты.Установить(Страница.next_cursor);
			ЗафиксироватьТранзакцию();
		Исключение
			ОтменитьТранзакцию();
			ВызватьИсключение;
		КонецПопытки;

		Если Страница.next_cursor = Курсор Тогда
			Прервать;   // новых событий нет
		КонецЕсли;
		Курсор = Страница.next_cursor;
	КонецЦикла;

КонецПроцедуры

Процедура ПрименитьРешение(Событие)
	// Событие.data: field, after.value, before.value, chosen, note, sources
	// Событие.case_id — id дела в рабочем месте; реквизиты дела (УИД, суд, номер):
	Дело = ЛД_Обмен.Запрос("GET", "/api/v1/cases/" + Формат(Событие.case_id, "ЧГ=0"));
	Поле = Событие.data.field;
	Значение = Событие.data.after.value;
	// Найти дело в 1С по Дело.uid (или Дело.court_code + Дело.case_number) и записать значение
	// в реквизит, соответствующий Поле. Рекомендуется — через регистр «ЛД_РешенияЮристов» (раздел 5).
КонецПроцедуры
```
Лента выдаёт события строго по порядку и без пропусков; повторное чтение с тем же курсором вернёт те же
события.

## 7. Производственный календарь

**Вариант А (коннектор, OData):** опубликуйте регистр `ДанныеПроизводственногоКалендаря` (раздел 1) и
используйте заготовку `connectors/примеры/календарь_1с.toml`.

**Вариант Б (код 1С):** раз в год, после утверждения переносов.
```bsl
Процедура ОтправитьПроизводственныйКалендарь(Год) Экспорт

	Запрос1С = Новый Запрос;
	Запрос1С.Текст =
	"ВЫБРАТЬ
	|	Данные.Дата КАК Дата
	|ИЗ
	|	РегистрСведений.ДанныеПроизводственногоКалендаря КАК Данные
	|ГДЕ
	|	Данные.ПроизводственныйКалендарь = &Календарь
	|	И Данные.Год = &Год
	|	И Данные.ВидДня В (&Нерабочие)";
	Запрос1С.УстановитьПараметр("Календарь", Справочники.ПроизводственныеКалендари.ПроизводственныйКалендарьРоссийскойФедерации());
	Запрос1С.УстановитьПараметр("Год", Год);
	Нерабочие = Новый Массив;
	Нерабочие.Добавить(Перечисления.ВидыДнейПроизводственногоКалендаря.Суббота);
	Нерабочие.Добавить(Перечисления.ВидыДнейПроизводственногоКалендаря.Воскресенье);
	Нерабочие.Добавить(Перечисления.ВидыДнейПроизводственногоКалендаря.Праздник);
	Нерабочие.Добавить(Перечисления.ВидыДнейПроизводственногоКалендаря.Нерабочий);
	Запрос1С.УстановитьПараметр("Нерабочие", Нерабочие);

	Дни = Новый Массив;
	Выборка = Запрос1С.Выполнить().Выбрать();
	Пока Выборка.Следующий() Цикл
		Дни.Добавить(ЛД_Обмен.ДатаISO(Выборка.Дата));
	КонецЦикла;

	Данные = Новый Структура("year, nonworking, source", Год, Дни, "1С: регламентированный календарь");
	Результат = ЛД_Обмен.Запрос("PUT", "/api/v1/calendar", Данные);
	// Результат.deadlines_changed — сколько сроков пересчитано
КонецПроцедуры
```
Имена объектов — по БСП; в вашей конфигурации могут отличаться. Ключу нужна область `calendar`.
Рабочее место проверяет, что нерабочих дней 100–140 (защита от неполной выгрузки).

**Вариант В (файл):** выгрузите все дни года в CSV `Дата;ВидДня` и используйте
`connectors/примеры/календарь_csv.toml`.

## 8. Справка по API

Полное описание с примерами — [integration.md](integration.md) и интерактивно на `https://<сервер>/api/docs`.

| Метод | Адрес | Область | Что делает |
|---|---|---|---|
| POST | `/api/v1/ingest/cases` | ingest | создать/обновить дела (массив) |
| POST | `/api/v1/ingest/observations` | ingest | значения полей по источнику (массив) |
| POST | `/api/v1/ingest/documents` | ingest | карточки документов без файла (массив) |
| POST | `/api/v1/ingest/documents/upload` | ingest | загрузить файл документа (multipart) |
| PUT | `/api/v1/calendar` | calendar | загрузить год производственного календаря |
| GET | `/api/v1/changes?after=N&actions=…` | export | лента изменений с курсора |
| GET | `/api/v1/export/values?format=xlsx` | export | файл итоговых значений |
| GET | `/api/v1/cases`, `/api/v1/cases/{id}` | read | реестр и карточка дела |
| GET | `/api/v1/fields` | read | справочник полей |

Коды ответа: `200` — хорошо (у пакетных методов смотрите `ok` по каждому элементу); `401` — неверный
или отозванный ключ; `403` — нет нужной области; `404` — не найдено; `413` — больше 1000 элементов;
`422` — неверный формат данных (в ответе написано, какое поле).
