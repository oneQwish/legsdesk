Миграции схемы базы данных
==========================

Новые таблицы сервер создаёт сам. Изменения СУЩЕСТВУЮЩИХ таблиц (новая колонка, индекс,
переименование) — это файлы в этой папке: NNNN_что_меняется.sql (NNNN — следующий номер по порядку).

При старте сервер выполняет файлы, которых ещё нет в таблице schema_migrations, по возрастанию
номера, каждый в своей транзакции, и записывает их туда. Ошибка в файле — сервер не стартует,
текст ошибки виден в `docker compose logs backend`; база при этом остаётся как была до этого файла.

Правила:
- уже выполненный на сервере файл не меняйте — добавьте новый с следующим номером;
- пишите так, чтобы повтор был безопасен: CREATE INDEX IF NOT EXISTS, ALTER TABLE … ADD COLUMN IF NOT EXISTS;
- то же изменение внесите в backend/app/models.py (для новых, пустых баз), это делает программист.

Какие миграции выполнены:  docker compose exec db psql -U lawdesk -c "select * from schema_migrations"
